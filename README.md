# TarihLine

Интерактивная историческая платформа с картой и временной шкалой для изучения истории Казахстана в мировом контексте.

MVP охватывает период 1900–2000. Карта показывает изменение политических территорий мира по годам. События и личности появляются только после публикации администратором.

## Технологии

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- MapLibre GL JS
- Esri World Ocean
- Vercel

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Проверка

```bash
npm run lint
npm run typecheck
npm run build
```
