# TarihLine

Интерактивная историческая платформа с картой и временной шкалой для изучения истории Казахстана XX века.

## Технологии

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Проверка

```bash
npm run lint
npm run typecheck
npm run build
```
