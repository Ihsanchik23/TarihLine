# TarihLine

Интерактивная историческая платформа с картой и временной шкалой для изучения истории Казахстана XX века.

Текущая версия содержит основной сценарий карты: период 1949–1963, события и личности, карточки с источниками, русский и казахский языки. Пока в базе нет опубликованных записей, интерфейс использует явно обозначенный тестовый набор.

## Технологии

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- MapLibre GL JS
- OpenFreeMap
- Vercel

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Проверка

```bash
npm run lint
npm run typecheck
npm run build
```

## Данные

Публичные записи загружаются из Supabase. Интерфейс показывает только записи со статусом `published`. Тестовый набор расположен в `src/data/prototype-records.ts` и автоматически перестаёт использоваться после появления опубликованных записей в базе.

Картографическая подложка загружается из OpenFreeMap на основе данных OpenStreetMap. Атрибуция отображается средствами MapLibre.
