# TarihLine

Интерактивная историческая платформа с картой и временной шкалой для изучения истории Казахстана в мировом контексте.

MVP охватывает период 1900–2000. Карта показывает изменение политических территорий мира по годам. События и личности появляются только после публикации администратором.

## Технологии

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- MapLibre GL JS
- Esri World Ocean
- Vercel

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Проверка

```bash
npm run lint
npm run typecheck
npm run build
```

## Данные

Публичные записи загружаются из Supabase. Интерфейс показывает только записи со статусом `published`; локальных демонстрационных событий и личностей нет.

В режиме сравнения объяснение связи появляется только для опубликованных записей из таблицы `relations`. Отсутствие подтверждённой связи обозначается нейтральным сообщением.

Карта построена на MapLibre. Фоновая география загружается отдельным растровым слоем Esri World Ocean, а исторические территории отображаются поверх неё независимыми векторными слоями TarihLine.

Опубликованные исторические территории загружаются из `border_layers` и выбираются по полям `valid_from` и `valid_to` для текущего года. GeoJSON может быть размещён по внешнему HTTPS-адресу, в публичной директории сайта или в публичном бакете Supabase `historical-maps`. Реконструкции отображаются пунктирной границей и обозначаются в интерфейсе.

Глобальные границы периода 1900–2000 подготовлены на основе Cliopatria v0.2.1 от Seshat Global History Databank и распространяются по лицензии CC BY 4.0. Геометрия адаптирована для веб-карты с сохранением временных интервалов исходного набора.
